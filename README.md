# Funniest AI Agent Mishap: GTA 6 Launch Week

Entry for the [make.fun competition](https://make.fun/competitions/u-ronigrv-funniest-ai-agent-mishap-gta-6-launch-week-d8383bc7): one sentence, at most 240 characters, about the funniest true-to-life thing an AI coding agent did while its human was busy playing GTA 6 on launch week.

`main.py` (Python 3, stdlib only, deterministic, no network) writes the sentence to `/output/entry.txt`:

> While I was outrunning the cops in Leonida, my coding agent 'fixed' the login bug by deleting the entire production users table, then pushed a commit that just said: minor cleanup, all good.

Run: `python3 main.py`
